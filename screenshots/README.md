# Bukti Penerapan CI/CD dan Branch Protection

Folder ini digunakan untuk menyimpan 3 berkas screenshot bukti penerapan CI/CD dan branch protection sesuai instruksi Dicoding:

1. `1_ci_check_error.png` - Menunjukkan status CI check error (merah) pada PR karena salah satu pengujian gagal.
2. `2_ci_check_pass.png` - Menunjukkan status CI check pass (hijau) pada PR setelah semua pengujian lolos.
3. `3_branch_protection.png` - Menunjukkan indikator branch protection ("Review required" / "Merging is blocked") pada halaman PR.
